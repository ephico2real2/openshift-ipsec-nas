The same DaemonSet pods report each node's metrics; OpenShift's own user workload monitoring scrapes them, the alerts fire per node, and the Cluster Observability Operator shows the dashboard in the console. The dashboard also lists the namespaces and claims that store data on the NAS, and whether each pod's node has a working tunnel.
