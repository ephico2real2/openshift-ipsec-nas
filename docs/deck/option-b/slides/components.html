Everything is a Red Hat operator or part of OpenShift, except Kyverno and our own chart. Kyverno is the most popular policy engine for Kubernetes in our assessment: the CNCF graduated it in March 2026, it has more than 9,000 GitHub stars, and LinkedIn runs it on 230+ clusters. Red Hat does not ship it; we run the open-source release as-is and support it ourselves, with no subscription. Why a DaemonSet: it is the only way to put a different certificate on each node without a MachineConfig, and it is where each node's metrics come from.
