Options A and C both put one certificate on every node, so the NAS sees the same identity many times. With libreswan's default, uniqueids=yes, the nodes keep replacing each other's tunnel; we measured that. The fix, uniqueids=no, changes the NAS for every peer it has, and our standard never shares an identity. Option B works with the NAS's defaults.
