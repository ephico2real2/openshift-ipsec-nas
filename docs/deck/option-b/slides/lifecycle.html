Join, renew, leave: one person, once

Join and renewal measured in the lab (evidence 29); removal: doc 20, B.11 and B.13

Joining and renewal need nobody. When a node leaves, Kyverno removes its certificate and tunnel definition and a cleanup policy removes the leftover Secret; the one human step is revoking that node's certificate at the CA, which is only possible because each node has its own.
