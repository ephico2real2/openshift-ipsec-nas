WHY AUTOMATION

A MachineConfig reaches a pool, never one node

Measured in the lab: shared identity, one tunnel at a time; own certificates, two tunnels · docs 51, 72

Per-node certificates through MachineConfigs would need one MachineConfigPool and one MachineConfig per node, made and renewed by hand, with a reboot each time. That is not manageable at any scale. Option B gives each node its own certificate through a Secret mounted into that node's own pod.
