THE REQUIREMENT

Our Linux hosts already do it: one certificate per host

conn mytunnel2
  left=<host IP>
  right=<NAS IP>
  leftcert="<host FQDN>"
  leftid=%fromcert
  rightid=%fromcert
  rightca=%same
  leftprotoport=tcp
  rightprotoport=tcp/nfs
  auto=start

Its own certificate

Every host is known to the NAS by its own certificate, from the enterprise CA.

Same CA, NFS only

The NAS is checked against the same CA; only TCP to NFS (2049) goes through the tunnel.

A valid, working setup

An OpenShift node has to meet the same standard.

Our enterprise configuration for Linux hosts, names and addresses removed · doc 70

This is our own enterprise standard for a regular Linux host connecting to the NAS. Three things matter: each host has its own certificate (the nickname is the host's FQDN), the NAS is checked against the same CA, and the tunnel covers NFS only. The question for OpenShift is how to give every node the same thing.
