THE MECHANISM

The certificate lands first, then the tunnel

Kyverno asks for the node's certificate.

cert-manager gets it signed by the enterprise CA.

The node's own DaemonSet pod imports it and labels the node.

Only then Kyverno writes the node's NNCP, and NMState brings the tunnel up.

doc 20, How it works · measured: first policy to tunnel in 47 s, no reboot

The order matters: the tunnel definition is only created once the certificate is on that node, so a node never tries to connect without its certificate. Nothing in this sequence is done by a person, and no node reboots.
