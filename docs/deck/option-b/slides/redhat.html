WHAT RED HAT DOCUMENTS

Red Hat's procedure: one certificate for every node of a role

One PKCS#12 and one CA file

Written by a Butane MachineConfig per role (master, worker), imported at boot.

One NNCP per node

By hostname, written by hand.

Rolled out pool by pool

The MCO updates one machine per pool at a time: each node reboots.

Nothing on renewal

That procedure is our Option A: one identity on every node.

OpenShift 4.19, Configuring IPsec encryption for external traffic · doc 10, doc 72

This is the procedure Red Hat documents for IPsec to external hosts. It works, and we measured it on our lab cluster as Option A. But it gives every node of a role the same certificate and the same identity, and the documentation says nothing about renewal.
