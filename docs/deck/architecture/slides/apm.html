Dynatrace trial tenant (doc 62, evidence 55) · doc 74, section 8

Because the data is Prometheus, an enterprise tool takes it as it is. Dynatrace was measured on a trial tenant: the Dynatrace Operator on the cluster, the tenant's setting for annotated Prometheus exporters, and our chart value metrics.dynatrace.scrape. The metrics arrived under their own names, gauges as gauges, counters as counters, per node. Any other APM that reads Prometheus can take the same data from the pods or from Thanos; that has not been tested.
