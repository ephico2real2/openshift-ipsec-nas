NFS mounts are hard: when the tunnel goes, the application does not fail, it waits. Without per-node data, every row looks like "the app is stuck".

evidence 36, 62; doc 60 · doc 74, section 6

This is why the dashboard is not optional. Every row happened in the lab. Because NFS mounts are hard, an application whose node lost its tunnel simply waits, and the symptom is always the same: the app is stuck. The dashboard turns that into a specific cause on a specific node: the selectors, a connection NetworkManager thinks is up, a flapping tunnel, a certificate, a node without a tunnel.
