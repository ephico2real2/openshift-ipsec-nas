The lab's OpenShift console, as a namespace reader (doc 61, Capture 8) · doc 74, section 5

The dashboard lives in the OpenShift console, through the Cluster Observability Operator, where operators and application teams already are. Each section answers one question, and the data in it was chosen for that question: the four numbers on-call needs first; each node's state and age; the checks that the numbers can be trusted; the per-node detail that says why a tunnel is down; the history; and the storage section for the application teams.
