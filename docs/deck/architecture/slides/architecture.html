FROM THE NODE TO EVERY DASHBOARD

One endpoint per node, every consumer

doc 74, section 4 · dashed: another APM, proposed and not tested

The whole path. Each node's pod publishes its node's metrics on port 9754. OpenShift's user workload monitoring scrapes every pod through a headless Service, so each node is scraped on its own, evaluates the twelve alert rules, and Thanos serves the data to the console's Perses dashboard and to Grafana. The same Service, annotated, is scraped by Dynatrace's ActiveGate; that was measured on a trial tenant. Any other APM that reads Prometheus could take the same data; not tested.
