Each node's state, by the question it answers

Is the node's tunnel up?tunnel_up, ike_sa_established, connection_configured, tunnel_established_timestamp

Prometheus text is what OpenShift's monitoring scrapes, what the console shows, and what Grafana and Dynatrace read: published once, read by all.

16 metric families, every one per node · doc 60, What is collected

The proposal is to publish every node's IPsec state as Prometheus metrics. Grouped by question, sixteen metric families, each labelled with its node. Prometheus's format is the one OpenShift's own monitoring scrapes, so there is no adapter, and the same endpoint feeds the console, Grafana and Dynatrace.
