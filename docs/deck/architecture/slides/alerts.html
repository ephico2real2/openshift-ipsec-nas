Four critical alerts, eight warnings, all per node. NfsWithoutTunnel is the one that protects the data: NFS requests on a node whose tunnel is down, from the platform's own NFS counters. TunnelFlapping matters because tunnel_up alone does not show a tunnel that keeps restarting. ExporterMissing fires for a selected node that no pod reports.
