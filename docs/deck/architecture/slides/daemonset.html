OUR IN-HOUSE DAEMONSET

ipsec-cert-sync: one pod per node, three jobs

privileged

sync

Imports its node's certificate into the node's NSS database, labels the node, re-imports on renewal, restarts a stuck tunnel.

privileged · host read-only

collector

Every 30 s reads libreswan, NSS, NetworkManager, the kernel's IPsec drops and the NFS mounts; writes 16 metric families.

unprivileged

metrics

Serves those metrics on port 9754: the pod's only network listener.

OpenShift has no way to put a different certificate on each node: a MachineConfig reaches a whole pool. This DaemonSet is the missing piece.

charts/ipsec-nas · doc 74, section 2

The DaemonSet is ours, in our chart. Each pod works only on its own node: Kyverno mounts that node's Secret into that pod and no other. The sync container is privileged because it writes the node's certificate store; the collector is privileged but mounts the host read-only, so it changes nothing; the metrics container, the only one listening on the network, has no privilege at all. The private key is removed from the node's disk right after the import.
