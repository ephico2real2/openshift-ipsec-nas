    (The driver removes an older archive only with --remove-archived-volume-path, which this install does not set.)
  A PV stuck like this: oc patch pv <pv> -p '{"spec":{"persistentVolumeReclaimPolicy":"Retain"}}'; oc delete pv <pv>
    (done for pvc-ae05a64c and pvc-99bab699; nothing deleted on the NAS)
