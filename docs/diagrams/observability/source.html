One pod per node, one source of truth for IPsec to the NAS

Our in-house DaemonSet puts one pod on each node that has a tunnel. It keeps that node's certificate in place, and it reports the node's tunnel, certificate and NFS state as Prometheus metrics, which OpenShift's monitoring, the console, Grafana and Dynatrace all read from the same endpoint.
